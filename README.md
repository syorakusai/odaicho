# 御題帳

妖怪イラスト生成用のモチーフをランダムに組み合わせ、文章のお題を作るシングルページツールです。

## 公開方法

このリポジトリは GitHub Pages からそのまま配信できる静的サイトです。公開するには、GitHub のリポジトリ画面で次の設定を行います。

1. **Settings** → **Pages** を開く。
2. **Build and deployment** の **Source** で `Deploy from a branch` を選ぶ。
3. ブランチに `main`、フォルダーに `/ (root)` を選び、**Save** を押す。
4. Pages 画面に表示される `https://<ユーザー名>.github.io/odaicho/` を開く。

サイト本体はルートの [`index.html`](./index.html) です。Jekyll の変換を行わず、そのまま配信するために `.nojekyll` も配置しています。

## 設定の保存

選択したジャンル、モチーフ数、文言テンプレートはブラウザーの `localStorage` に保存されます。同じブラウザー・同じ Pages URL から開き直すと設定が復元されます。

ブラウザーのサイトデータを削除した場合、シークレットモードを利用した場合、または別のブラウザーや端末で開いた場合には設定は引き継がれません。

## Android での利用

1. Android の Chrome で Pages の URL を開く。
2. Chrome のメニューから **ホーム画面に追加** を選ぶ。
3. ホーム画面に作成されたアイコンから起動する。

公開リポジトリでは、この HTML と収録データを含むすべての内容を誰でも閲覧できます。
